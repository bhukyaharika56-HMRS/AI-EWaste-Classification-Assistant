
# AI E-Waste Classification & Recycling Assistant

An AI-assisted educational project for identifying electronic waste and learning safe recycling practices.

## Features
- Image-based e-waste classification
- Recycling guidance
- AI chatbot
- Dashboard and category statistics
- Classification history
- CSV download

## Technologies
- Python
- Streamlit
- Pandas
- Pillow
- SQLite
- Google Gemini API (cloud AI version)

## Run locally
1. Install Python.
2. Install dependencies using `python -m pip install -r requirements.txt`.
3. Configure the required API key in `.streamlit/secrets.toml`.
4. Run `python -m streamlit run app.py`.

## Note
AI features require a valid API key and internet access.
